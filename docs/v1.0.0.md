# Neo-stream 1.0.0 — Téléphone et Android TV

- **Téléphone :** parcourez le catalogue, recherchez un titre et reprenez une lecture depuis votre profil.
- **Android TV :** naviguez dans le catalogue et dans le direct à la télécommande.
- **Développement :** retrouvez les sources du client Expo/React Native et son module de lecture Android dans le dépôt.

**Installation :** dans les fichiers de la release, choisissez `Neo-stream-Android.apk`. Le même APK est destiné aux téléphones et à Android TV. `SHA256SUMS.txt` permet de vérifier le téléchargement. Les archives « Source code » de GitHub ne sont pas des applications installables.
