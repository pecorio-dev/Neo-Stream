## ✨ Fonctionnalités

| Fonctionnalité | Description |
|---|---|
| 🎬 **Catalogue complet** | Films, séries et anime avec fiches détaillées, saisons, épisodes |
| 📺 **TV en direct** | Chaînes IPTV HD françaises via proxy FSTV (option premium) |
| 📥 **Téléchargements hors-ligne** | Films, épisodes, saisons ou séries entières — extraction intégrée, lecture hors-ligne (v1.4.0) |
| ⏭️ **Épisode suivant auto** | Enchaînement façon Netflix avec compte à rebours (v1.4.0) |
| ⏩ **Vitesse de lecture** | 0.5x → 2x mémorisée + minuteur de sommeil (v1.4.0) |
| ▶️ **Lecteur universel** | ExoPlayer natif (Android), media_kit (Windows/Linux), fallback automatique multi-sources + sélecteur de source intégré |
| 🚫 **Zéro pub** | Extraction côté client vers URL directe HLS/MP4 sur 15+ hébergeurs, filtre anti-faux-flux (v1.4.0) |
| 🔄 **Reprise auto** | Continue exactement où tu t'es arrêté, synchronisé sur tous tes appareils |
| 🔍 **Recherche avancée** | Historique local + filtres Films / Séries / Anime / ⭐ 7+ (v1.4.0) |
| 📡 **Catalogue hors-ligne** | Cache local — l'accueil reste instantané, même sans réseau (v1.4.0) |
| ❤️ **Favoris & historique** | Bibliothèque personnelle et historique de visionnage |
| 👤 **Multi-profils** | Jusqu'à 4 sous-comptes par compte |
| 🤖 **Recherche IA** | Recherche en langage naturel optionnelle |
| 📱 **Multi-plateforme** | Android, Android TV (D-pad), Windows, Linux — même compte partout |
| 🎨 **Design glassmorphisme** | Thème clair/sombre adaptatif, couleurs par genre, animations fluides |
| 🔄 **Mises à jour auto** | Vérification via GitHub Releases, téléchargement intégré |

## 🔧 Stack technique

| Couche | Technologies |
|---|---|
| **Frontend** | Flutter 3.32, Dart 3.x |
| **Lecteur vidéo** | ExoPlayer (Android), media_kit (Windows/Linux), videoPlayer (fallback) |
| **State management** | Provider |
| **Backend** | PHP 8.x, JWT, MySQL |
| **IPTV** | Proxy FSTV, chaînes HD françaises |
| **CI/CD** | GitHub Actions (build multi-plateforme auto) |
| **Distribution** | GitHub Releases, Inno Setup (Windows), AppImage (Linux) |

### Dépendances clés

| Package | Rôle |
|---|---|
| `media_kit` | Lecteur vidéo natif cross-platform |
| `provider` | Gestion d'état |
| `cached_network_image` | Images avec cache |
| `flutter_secure_storage` | Tokens JWT sécurisés |
| `shimmer` | Skeletons de chargement |
| `flutter_animate` | Animations fluides |
| `wakelock_plus` | Maintien écran allumé |
| `url_launcher` | Ouverture liens externes |

## 🔨 Build depuis les sources

### Prérequis
- Flutter 3.32+ (`flutter --version`)
- JDK 17 (pour Android)
- Linux : `libmpv-dev libgtk-3-dev ninja-build cmake clang pkg-config`

```bash
# Cloner
git clone https://github.com/pecorio-dev/Neo-Stream.git
cd Neo-Stream/app/app

# Dépendances
flutter pub get

# Build de développement
flutter run

# Builds release
flutter build apk --release        # Android
flutter build windows --release    # Windows
flutter build linux --release      # Linux
```

### Build Windows (installateur)
```bash
cd app
iscc neo_stream_setup.iss   # → app/installer/NeoStream-Setup-*.exe
```

## 👨‍💻 À propos

Je m'appelle **p3cori0**, j'ai 17 ans, et Neo-Stream est le projet le plus important de ma vie jusqu'ici.

Il y a deux ans, je ne savais pas coder. Zéro. Rien. J'avais une idée — une vraie plateforme de streaming, propre, sans pub, accessible — et aucun moyen de la construire. Alors j'ai appris. Le vibe coding d'abord, puis ligne par ligne, puis l'aide de l'IA pour aller plus vite. Deux ans de soirées, de weekends, de recommencements.

Ma mère me répète que je perds mon temps avec ce projet. Je n'ai pas arrêté.

Parce que le but de Neo-Stream, c'est simple : **casser les codes**. Pourquoi regarder un film doit coûter 13 €/mois, afficher des pubs, et te bloquer sur une seule plateforme ? Une contribution minuscule — 10 € une seule fois — pour des films, séries et anime en 720p/1080p, sans pub, sur tous tes appareils.

Neo-Stream existe, il tourne, des gens l'utilisent. Et ça, personne ne peut me l'enlever.
